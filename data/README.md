# Data

This directory contains public, synthetic-first repository artifacts.

Included here:

- synthetic LSAT-style item data used for local testing and pipeline development,
- batch evaluation outputs in `data/evaluations/`,
- human-readable evaluation reports in `data/reports/`,
- normalized canonical records and review-queue outputs produced by the public pipeline.

All items and evaluations are based on synthetic, scaffold, or anonymized LSAT-style content.

No official LSAT questions, passages, answer keys, OCR text, or source images are included in this repository.
